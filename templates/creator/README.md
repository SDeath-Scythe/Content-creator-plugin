# creator/

Your page's memory. content-creator skills read and write these files, so keep the folder in your project and commit it if you use git.

| File | Written by | Holds |
| --- | --- | --- |
| `page.md` | page-setup | Goal, language, platforms, cadence, posting hour, CTA, look, tools |
| `brand-profile.md`, `voice.md`, `audience.md`, `content-pillars.md` | page-setup (via the bundled skills) | Who the page is for and how it sounds |
| `idea-bank.csv` | daily-ideas, weekly-research | Scored ideas; `status` is new, picked, made, posted or dropped |
| `post-log.csv` | publish, weekly-review | One row per post per platform, with its numbers |
| `hook-wins.csv` | weekly-review | Your own best hooks; hook-mining reads it |
| `research/` | weekly-research | One file per week: outliers, teardowns, niche hooks |
| `reels/` | reel-pipeline, render-reel | One folder per reel: plan, assets, rendered files |
